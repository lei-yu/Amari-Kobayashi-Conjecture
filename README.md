# Amari–Kobayashi Conjecture

This repository contains the Mathematica source file `fisher_boolean_pairs_checks.wl`, accompanying the manuscript:

**A Sharp Fisher-Information Inequality for Boolean Pairs: Proof of the Amari–Kobayashi Conjecture**

For brevity and ease of verification, routine rational identities, derivative evaluations, and polynomial sign checks in the manuscript are delegated to the accompanying Mathematica source file. The corresponding statements are marked by CAS labels 01–26.

Selected certificates are also visualized in the supplementary figures at the end of the manuscript, plotted by using `fisher_boolean_pairs_plots.wl`.

The source file enables readers to independently reproduce and verify the corresponding symbolic computations used in the proof.
